Technical report and algorithm code submission
Final rounders (the top 40 teams) are required to submit a technical report and the source code for their algorithm to the Organizing Committee by August 6, 2026, at 14:00 KST (UTC+09:00).

Submission Method
Submit both the technical report and the algorithm source code via email to techreport@optichallenge.com.

Include your team name in the email subject and in both file names, using the following format:

Email subject: [OGC2026] TeamName
Technical report: [OGC2026_TechReport]_TeamName.pdf
Algorithm source code: [OGC2026_AlgorithmCode]_TeamName.zip

Technical Report
The technical report must not exceed 10 pages, including all figures, tables, and references.
The report must be submitted in PDF format.
The report must be prepared using either Microsoft Word or LaTeX, and each team must use one of the templates provided below.
Do not modify the formatting settings of the provided template, including the page size, margins, font size, and line spacing.
All Writing Guidelines boxes and their contents must be completely removed before submission.
The reports will be evaluated anonymously. Do not include any information within the report that could identify the team, including the team name, member names, affiliations, repository links, email addresses, acknowledgments, or other identifying details.

Algorithm Source Code
Submit the source code for the algorithm used at the time of submission.
The source code must be compilable or executable in the designated evaluation environment.
Submit all required source files as a single ZIP file.
The submitted source code must be consistent with the algorithm described in the technical report.
Include build.txt with build instructions if your algorithm requires a build process, such as compiling.
