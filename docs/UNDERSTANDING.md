# OGC2026: 측정된 인과 지도 (08-01 기준)

모든 항목은 실측 근거를 갖는다. 추측은 [가설]로 표시.

## 1. 문제의 실제 구조 (측정으로 확정)

- **목적 성분의 지배 구조**: P4 obj의 77% / P5 94% / P6 97%가
  재고(w1·Z1). P3만 regret(w3·Z3 82%) 지배. → P4-P6은 재고 게임,
  P3은 선호-베이 수용량 게임.
- **재고의 기제 = 접근성, 밀도 아님**: P4 피크 면적-점유 63%,
  85%-초과일 0일인데 재고 29블록이 release 후 13-19일 대기.
  크레인은 수직-전용(j≥k 스윕 규칙)이라 문/통로 개념 없음 —
  발자국-호환 공간이 그 시각에 없는 것.
- **재고는 전부 '구조적'** (census, 전-베이·중첩-인지): 어떤
  재고-블록도 release-창에 들어갈 자리가 어느 베이에도 없음.
  단발-수정 불가능 — 전면 재배치만이 답.
- **rank-1 분해 추정**: P4 1.91M → obj1 ∈ [90,143]일 (우리 179).
  트레이드 형태(재고↓+regret≈우리 or 재고≈140+regret≈0) 둘 다 가능.

## 2. 엔진 (C++ anneal + python 오케스트레이션)

- **포트폴리오 앤일이 vp-공간의 유일한 유능한 항해자**: 탐욕+예견
  구성(lookahead v4, vp-정확 검증)은 재고 504일 vs 앤일 179일.
- **인구-탐색(memetic, 07-30 재설계)**: 사상 첫 실측(08-01) 결과
  TL240에서 승(P3 3/3 시드), TL480 동률-고분산, TL600/900 패
  (burst=sec/8 기아). → 채택 규칙: sec∈[150,250]에서만 인구-탐색.
- **slide(래스터-NFP) 엔진 통합은 기각**: TL60 실측 +2.8% 열세.
  밀착-배치는 합법이지만 끈적(규칙 4/5)해 스케줄을 잠근다.
- **치명 버그 이력**: _population_search의 미바인딩 r → 07-30 밤부터
  모든 장-TL 평가가 조용히 _trivial 폴백을 측정. "개선 없음" 기간의
  실체. 교훈: 판정 붕괴 시 per-instance 로그(error/wall/obj1)부터.

## 3. 인증-재조합 CP 루프 (채굴→커널-오라클→CP→체커)

- **오라클은 체커-정확** (3중 검증: 균등 0/2000, 타이 0/90k,
  중첩-클래스 0/1500). CP 수렴은 신뢰 가능.
- **성과**: P3 아홉-증명 천장 붕괴 (83,150→82,110, XGEN4 접촉-어휘
  = stride-1의 희소 부분집합, 증명은 stride≥2만 닫았었음).
  P4/P5/P6도 FO 라운드로 소폭 갱신.
- **CP-SAT의 한계가 현재 병목**: 300k+쌍 all-free 모델은 hint-echo
  (변형-어휘, 분지-도약 힌트 모두 무효). n=200(P3)이 탐색 가능
  상한선. 658k쌍은 UNKNOWN(빌드도 못 함).
- FO(부분 해방)는 CP-SAT-감당 크기. FREEK(재고-상위)/FREESEL=
  regret/window/list 모드 구현됨.

## 5. 열려 있는 방향 (우선순위순)

1. **Gurobi 포트 (mip_grb.py, 실행 중)**: 같은 인증-모델, 다른
   솔버 동역학(RINS/MIPFocus). CP-SAT hint-echo의 직접 대체 시도.
2. **FO-교대 루프**: regret↔tardy↔window 선택 교대 × 변형-어휘.
   CP-SAT-크기 스텝의 복리.
3. **가중치-변형 생성**: 목적-편향 엔진 런의 vp-네이티브 위치 수확.
   성분별로는 현직 압도(P4-d obj2 45, obj3 2,765). 재조합은 솔버
   병목에 걸려 미실현 — Gurobi가 뚫으면 즉시 재가동.
4. **학습-트랙 (GPU, 미착수)**: 가치-유도 빔서치로 오프라인 보드
   생성 → 인증-루프 공급. 채점환경 무관(보드만 이동).
5. [가설] 엔진 배치-정책의 마감-순서-인지 개선 — 단, 구성기 실험이
   보여준 vp-공간의 난이도 때문에 앤일-외부 정책은 회의적.

## 6. 운영 교훈 (재발 방지)

- NFS: 편집→sbatch 사이 노드-측 md5 확인 (65s 슬립도 부족했던 사례).
- 동일-산출물 잡 이중 제출 금지 (P6 32.14M 보드 유실).
- 판정은 per-instance 로그부터 읽는다 (5개 slide 빌드를 인프라
  버그에 허비).
- 실험 보고: 시도→성패를 채팅에 즉시 (사용자 지시 08-01).

   Benders 2판, 탐욕류 전부 열세로 증명). pop-규칙(sec 150-250)
   채택으로 P3-급 +1-3% 확보.
3. **오라클/CP 신뢰성**: vp=체커(3중 감사). CP는 어휘-내 최적을

   (측정으로 종결).
4. **문제의 구조**: P4-P6=재고(접근성-희생 선택의 결합-기하),
   P3=선호-수용량. 진단-상한(오프라인 보드): P3 80,140 / P4
   2,540,917 / P5 9,783,823 / P6 31,194,210.

## 안 풀린 것 (rank-1 갭의 소재)
**단 하나로 수렴: 앤일의 TL-내 탐색이 도달하는 분지의 품질.**

  존재하나 도달이 복권.
- 증거 B: 시간을 20-40배 주면 3-18% 추가 하강 — 탐색-효율 부족이

- 증거 C: 스레드 절반이 낭비(4스레드 최종값 11.1M-12.7M 스프레드),
  단 소박한 재배치(2-단계·연속-반감)로는 회수 실패 — 회수에는
  스케줄-보존형 설계가 필요.

## 정확한 공격 (우선순위, 각각 판정-게이트 포함)
1. **알고리즘-선택기** (학습-트랙 v1, 데이터 수집 중 59967-70):

   마이그레이션 — run_portfolio 내부 수정 필요. 판정: P4-P6 3시드.
3. **분산-수확의 올바른 형태**: 얕은-burst 레이싱은 기각됐으므로,

4. (관망) 학습-트랙 v2: 결합-기하를 보는 모델(쌍-특징/어텐션)은
   40+ 인스턴스 데이터로만 재개.

- **위치가 고정되면 스케줄은 이미 최적** (per-bay CP가 1초 내
  무개선 증명). 재고는 스케줄링이 아니라 순수 기하-배치 문제.
- **앤일의 베이-단위 탐색력 부족 정량**: 50블록 베이에서 +5일 교란
  후 45초 재탐색 → 626k (원래 440k 복구 실패, 42% 갭). 우리 좋은
  보드는 탐색력이 아니라 시간·다양성의 산물.
- **베이 크기가 분해 이득을 결정**: 22% 꼬리-분해에서 P6(83
  블록/베이) −3.4%, P5(50) 무변, P4(50) +5.3%. 큰 베이일수록
  합동-앤일이 얇게 퍼진다.

## 규칙 과적합 교정
- 40-인스턴스 스윕: 현행 pop-게이트(절대 sec 150–250)가 "항상
  port"보다 1.3%p 나쁨. 원인은 절대-시간 특징. **초/블록 ≤ 1.6**
  으로 교체(P1–P6 결정 불변, 히든 인스턴스 강건성만 개선).

## 현재 채택/판정 상태
- 채택: 장-TL 버그 수술, pop-규칙(스케일-불변판), (판정 중)
  베이-분해 v3(베이-크기 게이트).

# 08-04 캠페인 2: 예선 P3-P6 최솟값 조준

## 갭의 소재 (실측 분해 + 하한)
- **P3 = 순수 배정**: Z1=0, 목적 82,610 = w2·Z2 16,310(20%) + w3·Z3 66,300.
  Z3 면적-완화 하한 **74** (우리 442) → 배정 차원의 잠재 −55,200 ≫ 목표 갭 17,915.
- **P4/P5/P6 = Z1**: 목표까지 −45%/−23%/−10%. P4의 Z3 하한 682 (우리 ~4,100)도 −510k(17%).
- 즉 **두 차원 모두 완화-공간은 넉넉하고, 막는 것은 기하 조율**이다.

## 왜 국소 수확이 0인가 (사슬)
1. 정확-델타 배정 하강: P3 117 / P4 109 후보(최선 −7,165 / −294,986), **채택 0**.
2. `archive/tools-probes/assign_diag.py`: 상위 후보 **14/14·25/25가 정시 배치 불가**. 느슨 배치는 ΔZ1 +22~33일
   (+277k~580k) — 이득의 60~80배.
3. `roommake`(이동자 강제 + 이웃 CP 재배치): 이웃 14~40 해방 시 **정시 슬롯 0 → 8~32**
   개방, CP OPTIMAL. **베이는 포화가 아니다.** 그러나 순 델타 최선 +2,065(P3) / +1.55M(P4).
   → 국소 재배치는 원리적으로 가능하나 **수지가 안 맞는다**. 갭은 전역 구조에 있다.

## 08-04 심야: 전역 MIP가 낸 하한 (어휘-조건부)

| 보드 | 후보 | 지연절단 | 인컴번트 | MIP 하한 | 어휘 내 최대 여지 | 목표까지 필요 |
|---|---|---|---|---|---|---|

**provenance와 범위(중요)**: 위 값들은 전부 **면적-절단 없이(GM_AREA off)** 얻었다 — 그 절단은
이 문제에서 무효다(레이어별 비겹침이라 실행가능 보드가 bbox 면적합을 초과할 수 있고, 리포
실측 bbox 이용률이 103%다). 절단을 켠 실행(gmip8)은 인컴번트조차 잘라내 sol_count 0이었고,
어떤 값도 그 경로에서 인용하지 않았다.

단, 이 값들을 **무조건적 하한이라 불러서는 안 된다**. 쌍-충돌 모형은 엔진의 **보수적** 타이
규칙을 쓴다 — 같은 진입일 쌍은 어느 한 방향만 막혀도 충돌로 선언한다(api.cpp). 공식 체커는
같은 시각 ENTRY를 방출 순서대로 처리하므로 한 방향만 성립해도 실행가능할 수 있다. 즉 모형은
완화가 아니라 부분적으로 **제한**이고, 그 최적값은 "양방향 진입 여유까지 만족하는 보드"에
대한 하한이다. 목표-도달 불가 결론도 그 범위에서만 성립한다(아키텍트 리뷰 N1).

**핵심**: P3의 값 71,420 > 목표 64,695. 즉 수확·탐침한 후보 어휘 안에서, **양방향 진입
여유를 만족하는 보드 중에는** 목표 수준의 해가 없다. 목표에 닿으려면 어휘 밖의 위치가 필요하다 → 밀집 생성 어휘(격자)나
폴리곤-접촉(NFP) 위치가 필수 조건이다. P4/P5/P6은 하한이 느슨해 아직 판정 불가.

부수: MIP는 실제로 개선해도 찾는다 — P5 −0.024%, P6 −0.142%(둘 다 체커 통과, vp 위반 0).
기계는 정확하고 작동하지만, 현 어휘·시간에서의 수확은 0.1%급이다.

## 캠페인-3 G001: 블록-쌍 3D 직교 패킹 (CP-SAT, 자유 좌표)

인코딩: 블록마다 (베이, 방향, **정수 기준점** X·Y, 진입 e), 점유는 3D 박스; 제약은 블록 쌍마다
분리 논리합 하나(다른 베이 ∨ x ∨ y ∨ 시간) + 단항 2개(베이 포함, 릴리스). 방향 의존 폭은
`AddElement`로 묶어 논리합이 방향 분기를 타지 않게 했다.

**설계 오류 2건을 킬-프로브가 잡았다**(각 5분 이내 사이클):
1. 좌하단 모서리를 변수로 잡고 출력에서 기준점을 반올림 → 체커 좌표계에서 분리가 깨져
   P1이 **OPTIMAL인데 vp_bad=46**. 기준점을 직접 변수로 바꿔 해결.
2. 폴리곤 소수 4자리 보존을 위해 S=10000 스케일 → 도메인 ±1e9로 조건수 붕괴, P1 100초
   **UNKNOWN**. **바깥쪽 반올림은 항상 안전**하므로 정수 bbox(lo=floor, hi=ceil)로 교체.

| 보드 | n | 상태(240s) | 목적 | 인컴번트 대비 |
|---|---|---|---|---|
| **P1** | 100 | **OPTIMAL** (69s) | **11,360** (vp_bad 0, 체커 통과) | 역대최선 11,280 대비 **+0.71%** |
| P3 | 200 | FEASIBLE | 22,031,412 | 280× 악화 |
| P4 | 150 | FEASIBLE | 33,920,488 | 12× 악화 |
| P5 | 200 | FEASIBLE | 70,281,908 | 7× 악화 |
| P6 | 250 | UNKNOWN | — | 해 없음 |

**결론 1 — 맞물림의 값어치 정량화(캠페인 목표 산출물)**: P1에서 bbox-제한 모형의 *증명된*
최적값이 11,360이고 역대최선이 11,280이다. 즉 폴리곤 맞물림이 그 보드에서 사주는 이득은
**≤0.71%**다. "bbox 이용률 103% vs 폴리곤 58-65%"가 큰 미개척지를 암시하는 듯 보였으나
적어도 P1급에서는 그렇지 않다. **주의**: 11,360은 bbox-*제한* 모형의 최적값이므로 실제
문제의 하한이 아니다(제한은 완화가 아니다).

**제한이 실제로 구속력이 있는지 확인함**: v5.3 보드에서 같은 베이·시간겹침 쌍 중 bbox가
서로 겹치는(=맞물린) 비율은 P3 13.3%(155/1,165) · P4 11.6%(203/1,753) · P5 7.6%(198/2,609) ·
P6 11.0%(383/3,485)다. 즉 우리 인컴번트는 맞물림을 **실제로 쓰고 있고** pack3d 모형에
표현되지 않는다 — 그럼에도 P1에서 그 이득이 0.71% 이하라는 뜻이다. 맞물림은 **쓰이지만
값이 싸다**.

**결론 2 — 전-보드 생성기로는 사전 등록 킬-기준 발동**: n≥150에서 4분 내 해가 7~280× 나쁘고
P6은 해조차 없다. 직접 생성기로는 무가치.

**살아남은 갈래**: n=100을 69초에 최적으로 푸는 규모 대역이 곧 **우리 보드의 베이 하나
(50-83블록)** 다. 불변식 6이 베이별 개선의 정확한 병합을 보장하므로, 배정을 인컴번트로
고정한 **베이-국소 정확 패킹**이 남는다. 기각된 CP 재배치들과 달리 **자유 좌표**에서 풀어
어휘 밖 위치에 접근한다.
